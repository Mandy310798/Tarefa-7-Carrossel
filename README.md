# Tarefa 7 - Carrossel

Este projeto é uma implementação de um carrossel de imagens utilizando HTML, CSS e JavaScript. Ele permite a navegação entre diferentes imagens de forma interativa e responsiva.

## Funcionalidades

- Transição suave entre imagens.
- Navegação através de botões de próxima e anterior.
- Responsivo para diferentes tamanhos de tela.

## Estrutura do Projeto

```
Tarefa-7-Carrossel/
├── Imagens/
│   └── [imagens utilizadas no carrossel]
├── index.html
├── style.css
└── script.js
```

- `index.html`: Estrutura básica do carrossel.
- `style.css`: Estilização do carrossel e seus elementos.
- `script.js`: Lógica de funcionamento do carrossel.
- `Imagens/`: Pasta contendo as imagens exibidas no carrossel.

## Como Utilizar

1. Clone o repositório:

   ```bash
   git clone https://github.com/Mandy310798/Tarefa-7-Carrossel.git
   ```

2. Navegue até o diretório do projeto:

   ```bash
   cd Tarefa-7-Carrossel
   ```

3. Abra o arquivo `index.html` em seu navegador preferido.
